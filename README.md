# medtools
My useful tools/links for medical life.

## 傳染病

- 流感：
    - [疫苗](https://www.cdc.gov.tw/Category/MPage/JNTC9qza3F_rgt9sRHqV2Q)：[公費對象](https://www.cdc.gov.tw/File/Get/om1fPXrhC0oM-kq9v-m4VQ)、[慢性病代碼](https://www.cdc.gov.tw/File/Get/om1fPXrhC0oM-kq9v-m4VQ)、[接種計畫](https://www.cdc.gov.tw/File/Get/vtqbmLpBSkjJdWKZ3-8BAw)。  
    BMI≧30。

    - [治療](https://www.cdc.gov.tw/Category/Page/fHHHNV-HWyYD00tnKeXsLA)：[使用對象一覽表](https://www.cdc.gov.tw/File/Get/SDmsd52in5uL-1DuplBZkQ)。  
        - 未滿5歲及65歲以上之類流感患者。
        - 孕婦及產後兩週內之婦女經評估需及時用藥者。
        - <em>**BMI ≥30**</em>。
        - 重大傷病、免疫不全、高風險慢性病。
        - 擴大使用對象至<em>**115-10-31**</em>。
            - 與高風險同住或其照顧者。
            - 安養、長照機構受照顧者及工作人員。
            - 醫事單位工作人員。(執登及非醫事人員)
            - 幼兒園托育人員、托育機構人員、居家托育人員(保母)。
            - 幼兒園、國小、國中、高中、高職、五專1~3年級生。
- 新冠：
    - [疫苗](https://www.cdc.gov.tw/Category/List/P2pYv_BSNAzqDSK8Qhllew)：[接種計畫](https://www.cdc.gov.tw/File/Get/SC4-9Qt0uYju9IVTw12dqQ)。  
        - 符合流感疫苗高風險對象條件。
        - 與前1 劑COVID-19 疫苗間隔12 週(84 天)以上。

    - [治療](https://www.cdc.gov.tw/Category/MPage/7UrQaVdMWdvd2J_l1wyehA)：[藥物領用方案](https://www.cdc.gov.tw/File/Get/Xhg2uZw0jwPeFl63dHJnGw)、[Liverpool](https://www.covid19-druginteractions.org/checker)。  
    年齡≧65歲(以「給藥年」減「出生年」≧65歲者)、氣喘、癌症、糖尿病、慢性腎病、心血管疾病（不含高血壓）、慢性肺疾（間質性肺病、肺栓塞、肺高壓、氣管擴張、慢性阻塞性肺病）、結核病、慢性肝病（肝硬化、非酒精性脂肪性肝炎、酒精性肝病與免疫性肝炎）、失能（注意力不足及過動症、腦性麻痺、先天性缺陷、發展或學習障礙、脊髓損傷）、精神疾病（情緒障礙、思覺失調症）、失智症、吸菸（或已戒菸者）、<em>**BMI≥30**</em>（或12-17歲兒童青少年BMI 超過同齡第95百分位）、懷孕（或產後6週內）、影響免疫功能之疾病（HIV 感染、先天性免疫不全、實體器官或血液幹細胞移植、使用類固醇或其他免疫抑制劑）
